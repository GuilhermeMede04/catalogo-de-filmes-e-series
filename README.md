# 🎬 Catálogo de Filmes e Séries

Um catálogo interativo de filmes e séries que permite explorar lançamentos de 2025, filtrar por gênero e visualizar detalhes completos dos títulos. Desenvolvido com JavaScript moderno (ES6+ Modules), HTML5 e CSS3.

## ✨ Funcionalidades

* *Catálogo Dinâmico:* Lista filmes e séries lançados em 2025.
* *Filtro por Gênero:* Permite ao usuário filtrar o catálogo por um gênero específico.
* *Detalhes Completos:* Exibe uma página de detalhes com sinopse, avaliação, pôster e mais.
* *Seções Dedicadas:* Áreas separadas para "Filmes" e "Séries" populares.
* *Sistema de Recomendações:* Sugere mídias similares na página de detalhes.
* *Design Responsivo:* Adaptável a diferentes tamanhos de tela (desktop e mobile).
* *Navegação Intuitiva:* SPA (Single Page Application) com navegação fluida entre seções.

## 🔌 API

O projeto consome a API do *The Movie Database (TMDB)* para buscar todos os dados, incluindo:
* Informações de filmes e séries
* Gêneros e detalhes
* Imagens, pôsteres e trailers
* Listas de recomendações

🔗 [Documentação oficial da API do TMDB](https://developer.themoviedb.org/docs)

## 🚀 Como Executar

Siga os passos abaixo para executar o projeto localmente.

### Pré-requisitos
* Um navegador WEB moderno (Google Chrome, Firefox, Edge, etc.).
* Conexão com a internet.

### Instruções
1.  Clone este repositório:
    * bash
    * git clone [https://github.com/GuilhermeMede04/catalogo-de-filmes-e-series.git](https://github.com/GuilhermeMede04/catalogo-de-filmes-e-series.git)
    

2.  Navegue até a pasta do projeto:
    * bash
    * cd catalogo-de-filmes-e-series
    

3.  Abra o arquivo index.html no seu navegador de preferência.

> *Nota:* O projeto precisa de uma chave de API do TMDB para funcionar. Ela já está incluída no código (api.js), mas em um projeto real, ela deve ser protegida.
